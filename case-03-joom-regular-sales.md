> Учебный кейс. Выполнен как практическое задание программы «Профессия: продакт-менеджер» (GoPractice). Продукт — Joom; работа не связана с компанией.

## Ситуация

Провела работу над практическим кейсом программы «Профессия: продакт-менеджер» от GoPractice. Кейс завершает изучение темы о реализации проекта на основе провалидированного решения.

Автор кейса — Анна Лазуткина (экс-CPO маркетплейса Joom).

В работе над кейсом мне помогал ментор GoPractice — *Никита Блинков (Lead Product Manager AI Infra/ML, в Open Innovation)*.

## Задача

Провести работу по реализации функциональности регулярных распродаж внутри международного ecommerce-маркетплейса (B2C). В частности:

- Оценить потенциал проекта через призму его ценности для пользователей и бизнеса;
- Проанализировать результаты экспериментального запуска;
- Сформировать оптимальное решение по итогам эксперимента и анализа;
- Проработать бизнес-логику решения;
- Спланировать работу над проектом и поставить задачи ответственным.

## Действия

1. Подготовила проект к защите на квартальном планировании.
   - a. Сформулировала гипотезы ценности для пользователей (покупатели и продавцы) и для бизнеса.
   - b. Выделила ключевые риски в основе гипотез ценности проекта. Предложила способы валидации рисков в течении 3 недель.
   - c. Сделала предварительный вывод о потенциале проекта на основе проведённых экспериментов. Поставила задачи аналитикам для получения полезных инсайтов для последующей работой над проектом.
   - d. Подготовила презентацию с идеями потенциальных решений. Подготовила описание логики с мокапами для наиболее перспективного.
2. Проработала бизнес логику при помощи инструмента - Business Model Canvas.
3. Поставила задачу на дизайнера для совместной проработки UX и взаимодействия с продуктом.
4. Ответила на вопросы разработки и дизайнера по предложенному решению.
5. Составила roadmap проекта для своей и смежных команд, участвующих в запуске. За квартал получится реализовать и запустить проект с проведением A/B теста с холдаутом.

## Результат

### Личный

- Выделила причины провала нескольких технических проектов, которые вела на работе.
- Короче формулировала свои мысли и отделяла важное от неважного для запуска проекта в срок.
- На каждом этапе работы над проектом продумывала и фиксировала дальнейшие шаги.

### По проекту

1. Проделана продуктовая работа над фичей. Пройден жизненный цикл проекта запуска распродаж с ограничением по срокам запуска.
2. Запущены и завершены A/B тесты с минимальными затратами по времени и ресурсам с последующей оценкой запуска на основе данных.
3. Поставлены OKR по проекту на основе данных.
4. Продумана и донесена бизнес-логика команде разработки и дизайна.
