> Учебный кейс. Выполнен как практическое задание программы «Профессия: продакт-менеджер» (GoPractice). Продукт — Tinder; работа не связана с компанией.

## Ситуация

Провела работу над практическим кейсом программы «Профессия: продакт-менеджер» от GoPractice. Кейс завершает изучение темы: **как находить и валидировать потенциальные решения задач и проблем пользователей продукта**.

Автор кейса — Люба Вязникова (экс-директор по продукту в Bumble).

В работе над кейсом мне помогал ментор GoPractice — *Никита Блинков (Lead Product Manager AI Infra/ML, в Open Innovation)*.

## Задача

Провести работу по валидации идеи фичи для Tinder, в частности:

- Собрать контекст проекта от менеджеров и стейкхолдеров;
- Выявить ключевые гипотезы в основе фичи;
- Проверить наиболее рискованные гипотезы.

Определить оптимальный способ решения задачи пользователей и проработать фичу перед ее реализацией, либо же отказаться от реализации, аргументируя причины.

## Действия

- На основе первичной постановки предложила гипотезы проблемы и решения, ценности для пользователей, ценности для бизнеса. Подготовила вопросы для уточнения контекста задачи у менеджеров: предварительная аналитика, проблемы пользователей и бизнеса, цели бизнеса, причины возникновения задачи, желаемые значения метрик.
- После получения дополнительного контекста, скорректировала гипотезы ценности для пользователей и бизнеса. Составила следующие шаги для подтверждения этих гипотез.
- Для каждой гипотезы описала дизайн исследования. Для JTBD-интервью подготовила план интервью с вопросами. Составила план с возможными вариантами дальнейших шагов в зависимости от результатов исследований.
- По транскрипции интервью с пользователями выделила основные причины ухода пользователей в другие мессенджеры. Выделила стоп-факторы для продолжения работы над проектом.
- Написала письмо руководителям с доказательствами, почему работу над проектом нужно остановить.

## Результат

Сформирован план для подтверждения гипотез.

- Отработан алгоритм продуктовой работы на этапе Discovery:
  - Уточнение контекста поставленной задачи для понимания причин возникновения задачи и желаемых целей бизнеса;
  - Составление гипотез проблемы и решения, гипотез ценности для пользователей и бизнеса;
  - План по подтверждению гипотез с проработкой дизайна исследований;
  - Проверка наиболее рискованных гипотез;
  - Обработка результатов исследований, выделение причин остановить работу над задачей;
  - Составление отчета со следующими шагами для менеджера.
- Сформулированы гипотезы ценности для пользователей и бизнеса на основе уточненного контекста.
- Предложены исследования для подтверждения и закреплен план для проведения JTBD-интервью.
