> Учебный кейс. Выполнен как практическое задание программы «Профессия: продакт-менеджер» (GoPractice). Продукт — Tinder; работа не связана с компанией.

## Ситуация

Провела работу над практическим кейсом программы «Профессия: продакт-менеджер» от GoPractice. Кейс покрывает тему, **как выявлять задачи и проблемы пользователей продукта**.

Автор кейса — Люба Вязникова (экс-директор по продукту в Bumble).

В работе над кейсом мне помогал ментор GoPractice — *Никита Блинков (Lead Product Manager AI Infra/ML, в Open Innovation)*.

## Задача

Провести JTBD-исследование пользователей Tinder, подготовить презентацию с результатами. Получить ответы на вопросы:

- Какие задачи продукт решает для пользователей;
- Какие у него есть альтернативы в рамках этих юзкейсов;
- В чем добавочная ценность нашего продукта относительно альтернатив в рамках основных юзкейсов;
- В чем добавочная ценность альтернатив относительно нашего продукта в рамках тех же юзкейсов.

## Действия

- Подготовила план с вопросами для проведения JTBD-интервью: адаптировала шаблон из курса после предварительного знакомства с рынком дейтинг-приложений.
- Провела 4 JTBD интервью по подготовленному плану с двумя женщинами и двумя мужчинами. Сделала транскрипцию диалогов и провела работу над ошибками в проведенных интервью.
- Классифицировала:
  - причины начала использования продукта респондентами
  - задачи, которые пробовали решить с помощью продукта
  - проблемы, с которыми сталкивались при решении задач
  - мотивацию, возвращаться в продукт для решения старых или новых задач
  - альтернативные способы решения задач
- Предложила гипотезы ценности для пользователей на основе выявленных задач и проблем респондентов.

## Результат

По итогам 4-х интервью сформировано 3 гипотезы ценности для нескольких задач респондентов: time killer, поиск близкого по духу и целям человека, поиск партнера. Для каждой гипотезы предложила решение и метрики для оценки их эффективности. Гипотезы требуют проверки.
